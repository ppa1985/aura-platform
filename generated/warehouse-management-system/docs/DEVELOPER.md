## Conventions

- **TypeScript everywhere**; `tsc --noEmit` must stay clean.
- **Parameterized SQL only** — never template a value into a query string.
- **Server Components for reads**, Client Components for interactive forms.
- **Zod** validates every API request body.
- **Naming**:
  - Entity directory: `kebab-case` (e.g. `warehouse/`)
  - Database table: `snake_case` plural (e.g. `warehouses`)
  - Component/class: `PascalCase`

2. Regenerate via the Aura platform (`POST /apps` with the same slug) OR

   - Extend the Zod schema in `src/app/api/<entity>/route.ts`.
   - Surface the field in `src/app/<entity>/page.tsx` (list) and

## Debugging tips

- **Bad SQL**: check the `DATABASE_URL`, then `SET search_path TO app_warehouse_management_system, public;` in a psql session to mirror the app.
- **Hydration mismatches**: confirm you're not reading `Date.now()` or random values at render time in a Server Component.
- **Self-heal loop looped forever**: inspect the generator log — the last failing
  `tsc` output is attached to the registry entry for this slug.
