## Conventions

- Base URL: the app's origin (e.g. `http://localhost:3000` in dev,
  `/generated/warehouse-management-system` behind the platform proxy).
- Content type: `application/json` on both sides.
- IDs are UUIDs.
- Timestamps are ISO-8601 strings (`created_at`, `updated_at`).
- Errors: `4xx` with `{"error": "<message>"}`; `5xx` for unexpected failures.
